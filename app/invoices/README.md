## invoices

Billing Workbench: Generate, issue and mark invoices as paid.

The screens are generated by SAP Fiori elements from the annotations in `annotations.cds`
(this folder) and the service `srv/service.cds`. There are no hand-written views.

### Starting the app

Start the CAP project from the project root and open the app in the browser:

```
npm run watch-invoices
```

http://localhost:4004/invoices/webapp/index.html

All apps together (launchpad): http://localhost:4004/index.html

#### Pre-requisites:

1. Active NodeJS LTS (Long Term Support) version and associated supported NPM version.  (See https://nodejs.org)
